CN-02 COLLAR NODE - SOLDERING SCHEDULE
========================================================================

Hole address is (col,row). Strips run LEFT-RIGHT: every hole in a row is
joined unless a cut separates it. CHECK THE STRIP MAP before soldering
anything into a hole you have not used yet.

SECTION 4 - PINS THAT MUST STAY UNCONNECTED
------------------------------------------------------------------------
Solder nothing into these holes. Let no wire or lead touch them.

  (col 14, row  5)  U1A.1    3V3       devkit 3V3 OUTPUT - shorting this kills the regulator
  (col 14, row  6)  U1A.2    EN        reset pin - pulling it low holds the chip in reset
  (col 14, row  7)  U1A.3    VP/IO36   unused GPIO - spare
  (col 14, row  8)  U1A.4    VN/IO39   unused GPIO - spare
  (col 14, row 11)  U1A.7    IO32      unused GPIO - spare
  (col 14, row 12)  U1A.8    IO33      unused GPIO - spare
  (col 14, row 17)  U1A.13   IO12      unused GPIO - spare
  (col 24, row 18)  U1B.14   IO0       unused GPIO - spare
  (col 14, row 19)  U1A.15   IO13      unused GPIO - spare
  (col 14, row 20)  U1A.16   SD2       FLASH PIN - devkit will not boot if loaded
  (col 24, row 20)  U1B.16   IO15      unused GPIO - spare
  (col 14, row 21)  U1A.17   SD3       FLASH PIN - devkit will not boot if loaded
  (col 24, row 21)  U1B.17   SD1       FLASH PIN - devkit will not boot if loaded
